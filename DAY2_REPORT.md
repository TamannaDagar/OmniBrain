# Day 2 Report

## Task Completed
Implemented the PDF Metadata Extraction module using the PyMuPDF library.

## Description
The module opens a PDF document and extracts metadata such as:
- File Name
- Title
- Author
- Subject
- Creator
- Producer
- Creation Date
- Modification Date
- Total Pages

The extracted metadata is saved in `output/metadata.json`.
