# Day 3 - PDF Text Extraction

## Objective
Implement a module to extract text from PDF documents using the PyMuPDF library.

## Work Completed
- Opened the PDF document.
- Read every page of the PDF.
- Extracted text from each page.
- Saved the extracted text into:
  - output/extracted_text.txt
  - output/extracted_text.json
- Added exception handling for missing files and runtime errors.

## Technologies Used
- Python
- PyMuPDF (fitz)
- json
- os

## Output
The program successfully extracts text from every page of the PDF and stores it in both TXT and JSON formats.
