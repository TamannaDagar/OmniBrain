## What is collection in Qdrant?
Collection in Qdrant is similar to the table in the database that is used to store the vectors.

PostgreSQL                  Qdrant
Database                    Qdrant
Table                       Collection
Row                         vector

## Why we use Qdrant?
Qdrant is used for storing the large No. of vectors because we cannot store all the vectors generated by the embedding models in .npy files.


It helps for semantic search.

---

## Why we choose size 384?
Because we are using model- "all-MiniLM-L6-v2" which generates the embeddings of  the sentence in 384 vectors.
---

## Why are we using Cosine Distance?
Cosine Distance is the most important factor that is used for searching in "all-MiniLM-v6-v2" efficiently.

It identifies each vector and the similarity between them using the cosine angle.

---

## Why check if a collection already exists before creating it?
Because if a collection already exist with a particular name , so we can use the existing or create a collection with different name.
