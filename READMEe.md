# PDF Processing Project

## Overview

This project is developed using Python and PyMuPDF.

It extracts information from PDF files and converts the extracted data into structured JSON format.

---

## Features

- PDF Parsing
- Metadata Extraction
- Page-wise Text Extraction
- Structured JSON Output
- Password Protected PDF Handling
- Corrupted PDF Handling
- Logging
- Unit Testing

---

## Technologies Used

- Python
- PyMuPDF (fitz)
- JSON
- Logging
- OS Module
